# Toolbelt

None of what's below is part of Company Brain OS. Each entry here is external,
separately maintained, and updates on its own schedule. Adopt only what's useful to how
you work; the template functions completely without any of it.

## Superpowers (recommended)

External, separately maintained, not part of Company Brain OS. Ships as a plugin in
Anthropic's official Claude Code plugin marketplace: workflow skills for brainstorming,
writing plans, dispatching parallel agents, systematic debugging, and test-driven
development, the kind of structured multi-step work this template's daily flow doesn't
try to cover on its own. Install through Claude Code:

```
/plugin marketplace add anthropics/claude-plugins-official
/plugin install superpowers
```
