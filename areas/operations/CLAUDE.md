# areas/operations/

Internal processes: admin, finance, vendors, and anything that keeps the
organization running day to day (not client-facing, not published).

## What lives here

One file or subfolder per process or function (e.g. `finance.md`,
`vendors/`, `admin.md`).

## Conventions

- Name files after the process or function, not the tool used to run it.
- Point to the system of record (accounting software, vendor contracts)
  rather than duplicating its data here.
- Recurring processes: capture the steps once and update in place, rather
  than adding a new file per cycle.

## Live status

Current blockers, pending renewals, and next actions live in `memory/`
(see `memory/CLAUDE.md`). This area holds the reference process, memory
holds what is live right now.
