# areas/clients/

External work: every client, customer, or engagement this organization does
work for.

## What lives here

One file or subfolder per client. Use a consistent slug (e.g.
`client-name.md` or `client-name/`) so the pattern stays predictable as the
roster grows.

## Conventions

- Name files after the client, not the project or contract.
- Keep engagement history, deliverables, and contacts inside the client's
  own file or folder, rather than scattered across other areas.
- Closed or lost clients: mark clearly rather than deleting, so history
  stays searchable.

## Live status

Active engagements, deadlines, and next actions live in `memory/` (see
`memory/CLAUDE.md`). This area holds the detail, memory holds the current
state and points back here.
