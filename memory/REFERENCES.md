# References

Index of the `reference_*` files in `memory/`: pointers to external resources
(repos, deployments, dashboards, shared folders, tool setups). Read on demand,
never at session start: a pointer matters when you work on that thing, not
every session. The project file that uses a reference links it with a
`[[wikilink]]`.

These rows live here and not in `MEMORY.md` because the index is the one file
auto-loaded on every session and it has a size cap: it carries only what the
daily briefing needs to build priorities. Same one-line row format as
`memory/CLAUDE.md`; the `reference_*` files themselves stay in `memory/`.
