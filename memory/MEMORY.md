# Memory

Source of truth for active projects, strategic directions, and references.
This file is auto-loaded at the start of every session: it is the dashboard,
one line per item. The daily briefing (`/daily-briefing`) reads this to build
priorities. The session debrief (`/session-debrief`) updates it when status
changes. Each item's own file holds the full context; operating rules for
this layer live in `memory/CLAUDE.md`, read it before writing anything here.
